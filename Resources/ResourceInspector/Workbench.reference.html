Reference-only capabilities

This browser page defines the intended interaction and visual direction. It is not a renderer contract.

  • Browser drag-resizing and responsive reflow
  • Native HTML focus, menus, dialog, form persistence
  • Simulated loading and error presentations

Native implementation target: retained CkSlateLayout controls, bindings, menus, splitters, tables, tabs, repeaters, and registered custom containers.

Workbench reference

The workbench is a visual acceptance target for Resource Inspector. Its interactive browser details clarify expected behavior; the native test host remains responsible for production parsing, retained view ownership, and test coverage.
